# Desktop Vocabulary Coach 开发计划

> 依据：`docs/Desktop_Vocabulary_Coach_Design.md`（v1.0）
> 原则：小步交付、每个 Sprint 结束必须有可运行版本、构建通过、测试通过、完成手工验收后再进入下一轮。
> 技术基线：.NET 10 LTS + WPF + SQLite + Generic Host + MVVM，AI 永远可选。

## 1. 里程碑总览

| Sprint | 主题 | 关键交付 | 主要验收 | 状态 |
| --- | --- | --- | --- | --- |
| 1 | 桌面骨架与托盘 | 解决方案分层、Host/DI/日志、主窗口、托盘、手动卡片、测试工程 | 启停正常、关闭到托盘、手动弹卡、退出释放资源 | ✅ 完成 |
| 2 | SQLite 与本地词库 | EF Core 实体/迁移、词库导入器、示例词库、按词查询 | 首次启动建库、重复导入去重、升级不覆盖进度 | ✅ 完成 |
| 3 | 随机后台调度 | 随机间隔循环、勿扰时段、每小时上限、空闲/全屏检测、暂停恢复 | 缩短间隔可验证、非法状态不弹、恢复后不补弹 | ✅ 完成 |
| 4 | 反馈与复习闭环 | 反馈持久化、ReviewLogs/LearningSessions、IReviewScheduler（SM-2）、复习优先 | 三种反馈正确更新、关闭不算认识、逾期优先 | ✅ 完成 |
| 5 | 自适应与设置 | 最近 20 次统计、难度自适应、设置界面、今日统计、备份 | 反馈影响难度、设置持久化、统计一致 | ✅ 完成 |
| 6 | AI 与发布 | AI Provider（Mock/OpenAI 兼容）、缓存与降级、安装包、DPI/多屏/长跑 | AI 关闭/失败不影响核心、Key 安全、安装升级可验证 | ✅ 完成 |

## 2. 实施顺序与依赖

```text
Sprint 1 骨架/托盘/卡片
        │
        ▼
Sprint 2 SQLite 词库（词源接口不变，替换内存示例词源）
        │
        ▼
Sprint 3 随机调度（消费 PauseState / 系统状态 / 卡片展示器）
        │
        ▼
Sprint 4 反馈落库 + 复习算法（消费 ReviewLogs，驱动推荐优先级）
        │
        ▼
Sprint 5 自适应 + 设置 + 统计 + 备份
        │
        ▼
Sprint 6 AI 增强 + 安装包 + 兼容性长跑
```

不允许跳级：Sprint 3 之前必须有可持久化的词库，Sprint 4 之前必须有稳定的调度循环记录会话，
否则反馈数据无法解释，自适应也无从谈起。

## 3. 每个 Sprint 的质量门禁

进入下一个 Sprint 前必须同时满足：

1. `dotnet build VocabularyCoach.sln` 0 error（新增警告需说明）。
2. `dotnet test VocabularyCoach.sln` 全绿；新增业务规则必须有单元测试（调度、推荐、复习时间）。
3. 手工验收清单逐项通过，并在 README 或 `docs/sprint-XX.md` 记录实际结果与未完成项。
4. 数据/日志路径不写入安装目录；退出不丢已提交反馈；API Key 不落明文。
5. 更新 README 的运行方式、已知限制与本计划表格状态。

## 5. Sprint 2（已完成）：SQLite 与本地词库

**目标**：把内存示例词源替换为可持久化的本地词库，并建立可重复执行的导入流程。

已完成：

- [x] 引入 EF Core SQLite + 迁移；数据库位于 `%LocalAppData%\DesktopVocabularyCoach\vocabulary.db`。
- [x] 实体与配置：`Words`、`WordDefinitions`、`UserWordProgress`、`ReviewLogs`、
  `LearningSessions`、`UserLearningProfile`、`AppSettings`、`AiGenerationCache`。
  - `NormalizedWord` 唯一索引；`DueAt`、`WordId`、`ShownAt`、`ReviewedAt` 等索引。
  - 所有 `DateTimeOffset` 统一转 UTC 并以 ISO-8601 字符串存储。
- [x] 启动引导：自动迁移、确保用户档案存在、按 `seed.version` 导入内置词库。
- [x] JSON/CSV 导入器：按 `NormalizedWord` 去重，支持新增/更新/跳过/失败统计，
  分批事务保存，不覆盖 `UserWordProgress`；主窗口提供「导入词库…」入口。
- [x] 首批 5,000 词种子词库（ECDICT，MIT）：难度 1–4、词频、音标、词性、中文释义；
  来源、筛选规则与许可见 `data/seed/README.md`、`docs/licenses/`。
- [x] 基于数据库的 `IWordCardSource`（难度上限 + 词频靠前随机）与本地查词。

验收结果（实际执行）：

- 首次启动自动建库：迁移 + 导入 5,000 词约 3.2 秒，`vocabulary.db` 约 1.3 MB。
- 第二次启动 `seed.version` 命中，不再重复导入，词库仍为 5,000 词。
- 重复导入同一文件：新增 0、跳过 5000，无重复单词。
- 更新词条（释义/难度/词频）后 `UserWordProgress` 的重复次数与间隔保持不变（自动化测试）。
- 查词大小写不敏感（`Season` → `season`），返回全部释义；不存在的词给出明确提示。
- 导入非法词条返回可读错误与统计，不影响有效词条；CSV 缺少必需列时整体拒绝。
- 新增 9 个 Infrastructure 集成测试（临时 SQLite 文件），全解决方案 36 个测试通过。

风险 / 注意：

- 词库许可证必须核对，不使用来源不明的商业词典数据（当前使用 ECDICT MIT）。
- 迁移必须向前兼容，后续 Sprint 升级不能丢用户数据。

## 6. Sprint 3（已完成）：随机后台调度

**目标**：让卡片在合理时机自动弹出，并在不适合时安静等待。

已完成：

- [x] `PopupSchedulerService` 随机间隔（默认 12–35 分钟，支持小数分钟），等待分片执行，
  不使用 `Thread.Sleep` 或忙循环；暂停/退出数秒内打断等待。
- [x] 勿扰时段（默认 22:30–08:00，本地时区，支持跨零点；起止相同表示禁用）。
- [x] 每小时上限（默认 4 次），滑动一小时窗口，仅统计自动弹卡。
- [x] `WindowsSystemStateMonitor`：`GetLastInputInfo` 空闲检测（默认 3 分钟）、
  `GetForegroundWindow` + `GetMonitorInfo` 全屏检测、`OpenInputDesktop` + WTS 会话状态锁屏检测；
  检测失败保守处理（暂缓并记录日志）。
- [x] 暂停/恢复：托盘暂停立即生效，恢复后重新随机等待，不连续补弹。
- [x] 状态不允许时短延迟重试；成功弹出后总是重新安排随机间隔。
- [x] 主窗口显示「自动提醒：已启用，下次检查约 HH:mm」，每 5 秒刷新。

验收结果（实际执行）：

- 临时把间隔改为 1.2–1.8 秒后，真实 App 自动弹出 `century`、`reach` 等卡片，
  超时自动关闭并按随机间隔继续。
- 将每小时上限设为 2：两次弹出后日志出现
  「跳过本次自动弹卡：最近一小时已弹出 2/2 次」，不再弹出。
- 真实系统状态检测在无交互会话中识别到全屏应用，日志出现
  「跳过本次自动弹卡：前台为全屏应用」。
- 调度循环集成测试覆盖：允许状态自动弹卡、锁屏不弹、勿扰不弹、暂停不弹、
  恢复后重新弹卡、达到上限后停止、`StopAsync` 2 秒内完成。
- 新增 `QuietHours`、限流窗口、随机间隔、系统状态判定等测试；全解决方案 76 个测试通过。

风险 / 注意：

- 全屏检测在无边框全屏、多显示器、DPI 缩放下存在边界情况，Sprint 6 需要专项验收。
- WTS 会话状态接口不可用时回退到桌面句柄判断，不阻塞弹出。
- 系统时间跳变（休眠唤醒、改时钟）由 `Task.Delay` 的单调计时与每次重算截止时间处理，
  不会瞬间连续触发。

## 7. Sprint 4（已完成）：反馈与复习闭环

**目标**：用户反馈可靠落库，并驱动下一次复习时间。

已完成：

- [x] 三档反馈持久化（单事务）：`UserWordProgress` + `ReviewLogs` + `LearningSessions` 同时提交。
- [x] `LearningSessions.Action` 覆盖 `Recognized / Vague / Unknown / Dismissed / Snoozed / Timeout`；
  `DurationMs` 记录展示时长，`Source` 区分自动/手动。
- [x] `IReviewScheduler` 抽象 + 简化 SM-2：认识 1→3→×ease，模糊短间隔，不认识 10 分钟重学并累计遗忘；
  难度系数限制 1.3–3.0，间隔限制 10 分钟–365 天，≥60 天记为已掌握。
- [x] 推荐引擎：到期复习按 `DueAt` 升序优先；逾期 >6 小时无条件复习；压力低时按 60/40 混合新词。
- [x] 卡片关闭、超时、稍后提醒只写会话，不更新进度、不写复习日志。
- [x] 卡片模型增加数据库 Id，未持久化卡片（测试/内存）不写学习记录。

验收结果（实际执行）：

- 真实 App 点击「认识」后：`repetition=1`、`intervalDays=1`、`Status=Learning`、
  `DueAt` 为次日；`ReviewLogs=1`（Good/Recognized/Manual）、`LearningSessions=1`
  （Recognized/Manual，时长约 1.1 秒）。
- 第二次「认识」→ 3 天；「不认识」→ 重复次数归零、Lapse+1、10 分钟后重学（集成测试）。
- 关闭/超时/稍后提醒 → 只有学习会话，无进度与复习日志（集成测试）。
- 逾期 1 天以上的词优先于新词；压力阈值为 2 时队列压力高优先复习（单元测试）。
- 新增 SM-2、推荐规则、落库事务、到期查询等测试；全解决方案 107 个测试通过。

风险 / 注意：

- 简化 SM-2 不是 FSRS，参数（ease 增减、间隔阈值）后续可根据实际体验调整。
- 反馈落库失败只记录错误日志，不阻塞 UI；恢复策略与重试在 Sprint 5 完善。

## 8. Sprint 5（已完成）：自适应与产品设置

**目标**：系统能根据反馈调整难度，用户能调整提醒、学习、显示设置。

已完成：

- [x] 最近 20 次有效反馈统计（排除关闭/超时/稍后提醒），写入 `UserLearningProfile`。
- [x] 自适应规则：认识 > 80% 且不认识 < 10% → 难度 +1 档、新词比例 +0.05；
  不认识 > 35% → 难度 -1 档、新词比例 -0.1；样本 < 10 不调整，每次最多一档。
- [x] 设置窗口（提醒 / 学习 / 显示 / 数据 / AI 占位），保存到 `AppSettings`（JSON），
  启动加载并覆盖 `appsettings.json` 默认值；调度、检测、卡片、推荐实时读取。
- [x] 今日学习统计窗口：弹卡总数、反馈分布、关闭/稍后/超时、今日学习词数、待复习数量。
- [x] 数据库备份（SQLite 在线备份）与恢复（校验 Words 表、重启提示）。
- [x] 浅色/深色主题，切换后应用于新打开的卡片/窗口。
- [x] 设置保存后调度立即使用新间隔/勿扰/限流参数；暂停与提醒开关独立。

验收结果（实际执行）：

- 设置保存后重新创建设置服务，17 个字段全部与保存值一致；非法勿扰时段被拒绝，越界值自动归一化。
- 自适应上调：17/20 认识 → 难度 2→3、新词比例 0.60→0.65；下调：8/20 不认识 → 3→2、0.60→0.50；
  样本 5 次不调整；手动模式只更新统计。
- 统计：7 条今日会话与统计数字完全一致，昨日会话不计入；待复习数与进度表一致。
- 备份：在线备份文件可正常打开、词条一致；恢复覆盖目标库；非应用数据库被拒绝。
- 真实启动：`AddAdaptiveDifficulty` 迁移成功，设置加载（提醒 True / Light / Smart）。
- 新增自适应、设置持久化、统计、备份、AI、安装相关测试；全解决方案 156 个测试通过。

风险 / 注意：

- 设置界面的数字输入依赖 WPF 绑定转换，非法文本会保留旧值而不报错；后续可加输入校验提示。
- 主题切换不重建已打开窗口，属于刻意取舍（避免重建主窗口状态）。

## 9. Sprint 6（已完成）：AI 增强与发布准备

**目标**：在不影响核心离线体验的前提下提供可选 AI 增强，并完成可交付安装包。

已完成：

- [x] `IVocabularyEnrichmentProvider` 抽象 + 离线 Mock + OpenAI-compatible 实现。
- [x] 中美主流服务预设（OpenAI / Anthropic / Gemini / DeepSeek / Moonshot / Qwen / Zhipu /
  SiliconFlow / 自定义），模型与 Base URL 可修改。
- [x] 缓存优先：卡片只读 `AiGenerationCache`，无缓存后台生成，下一次展示生效；
  请求 20 秒超时、失败静默回退，不阻塞 UI。
- [x] API Key 使用 Windows DPAPI 加密保存，不进入配置/数据库/日志；设置页可测试连接与清除。
- [x] 首次启动向导：英语水平、提醒节奏、勿扰时段、测试弹窗。
- [x] 浅/深色主题；PerMonitorV2 DPI；卡片按鼠标所在显示器工作区定位。
- [x] Inno Setup 安装包（自包含 win-x64、按用户安装、中文界面），升级保留数据、卸载保留学习数据。

验收结果（实际执行）：

- AI 关闭/未配置 Key/请求失败时，卡片与学习闭环完全正常；Mock 模式可离线生成并写缓存。
- OpenAI-compatible 请求路径、Bearer 鉴权、响应 JSON 解析通过单元测试；未配置 Key 时不会调用 Provider。
- DPAPI：Key 文件无明文，读取往返一致，删除后为空。
- 首次启动向导保存设置并标记完成；再次启动不再显示。
- 安装包 0.6.0 编译成功（约 56 MB）；静默安装 → 启动 → 静默卸载：安装目录删除，
  `%LocalAppData%` 数据库保留。
- 全解决方案 156 个测试通过。
风险 / 注意：

- 安装包未代码签名，SmartScreen 可能提示；正式分发建议购买签名。
- 混合 DPI 多显示器、长时间运行需在实机环境补充人工观察。
