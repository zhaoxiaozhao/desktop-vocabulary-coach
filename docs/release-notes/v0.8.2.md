# Desktop Vocabulary Coach 0.8.2

Windows 10 / 11 x64 桌面英语单词教练：常驻系统托盘，在合适的时间随机弹出一张轻量单词卡，
用「认识 / 模糊 / 不认识」或「A–D 选释义（含 E：不认识）」快速反馈，按 SM-2 自动安排复习。
核心功能完全离线，无需账号，不上传学习记录；AI 例句可选。

## 本次发布

- 开机自动启动（可在设置中开关）：通过当前用户 `HKCU\...\Run` 注册，无需管理员权限，
  开机后静默进入系统托盘，不弹出主窗口；卸载安装包时自动清理启动项。
- 生词捕获：任意应用中选中单词/短语，按 `Ctrl+Alt+W` 加入生词本并立即进入复习队列；
  支持 1–5 个英文单词的短语，未收录词可填写中文释义；不保存来源与上下文。
- 内置词库扩充到 **18,914** 词（ECDICT，MIT），含音标、难度、词频与中文释义。
- 选择释义模式：A–D 四个选项 + 固定 **E：不认识**，答对记为认识，答错/选 E 记为不认识。
- 设置、深浅主题、多屏 DPI、今日统计、数据库备份/恢复、首次启动向导。
- 197 个自动化测试通过（Core 33 + Application 124 + Infrastructure 40）。

## 安装

1. 下载 `DesktopVocabularyCoach-Setup-0.8.2.exe`（约 56.7 MB / 54.1 MiB）。
2. 双击安装。按用户安装到 `%LocalAppData%\Programs\Desktop Vocabulary Coach`，无需管理员权限。
3. 安装包自带 .NET 10 运行时，无需预装 .NET。

> 安装包未购买代码签名证书，Windows SmartScreen 可能提示「已保护你的电脑」。
> 可先核对下方 SHA256，再选择「更多信息 → 仍要运行」。

## 数据位置

```text
%LocalAppData%\DesktopVocabularyCoach\vocabulary.db   学习数据（SQLite）
%LocalAppData%\DesktopVocabularyCoach\logs\            按天滚动日志
%LocalAppData%\DesktopVocabularyCoach\ai.key           AI Key（DPAPI 加密，可选）
```

升级与卸载不会删除学习数据。彻底清理需手动删除 `%LocalAppData%\DesktopVocabularyCoach`。

## 已知限制

- 仅支持 Windows 10 / 11 x64，暂不支持 ARM64 与 Windows 7/8。
- 捕获热键固定为 `Ctrl+Alt+W`，暂不支持自定义组合键。
- 开机自启仅对当前 Windows 用户生效。
- 混合 DPI 多显示器仍需在实机环境人工验收。
